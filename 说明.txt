《住户登记》文本编辑版

文件：
  index.html —— 游戏界面与交互代码；一般不用修改。
  story.txt  —— 可以直接用记事本/VS Code 修改的剧情与文字。

修改方式：
1. 打开 story.txt，找到【Day1开场正文】【群聊2正文】【公告正文】等栏目。
2. 只改栏目下面的文字，保留【栏目标题】及【】符号。
3. 保存为 UTF-8。繁体中文与简体中文都支持。
4. 在 GitHub 仓库根目录同时上传 index.html 和 story.txt（不要改文件名）。
5. 以后只要更新 story.txt 并提交，线上网页会显示更新内容。
   如果手机仍显示旧内容，可以刷新网页或稍后重新进入。

群聊1～7分别是 Day 1 的七条消息。
群成员名单、通讯录名单、住户资料也都可以修改。
当前每条消息的头像样式和显示顺序仍由 index.html 控制，
但是发言人名字、聊天正文、玩家回复都可以直接在 txt 里修改。

如果本地用 Chrome 双击 index.html：
浏览器可能禁止网页自动读取旁边的 story.txt。
届时网页会提供“选择 story.txt”按钮，选择同目录中的文本文件即可试玩。
正式通过 GitHub Pages 的 https:// 网页访问时，会自动读取 story.txt。

注意：本次是剧情与界面分离的第一版；剧情时间、分支触发、数值变化
依然由 index.html 内的游戏逻辑管理，暂未提供通过文本自定义新分支的功能。
