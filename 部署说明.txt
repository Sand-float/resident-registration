《住户登记》Day 1 · 对话交互与消息节奏修正版

更新 GitHub Pages：
1. 下载并解压此 ZIP。
2. 打开 sand-float/resident-registration 仓库的根目录，Add file → Upload files。
3. 将解压后的所有文件及 assets 文件夹一起上传，覆盖旧版同名文件。
4. 提交 Commit changes 后，等待 GitHub Pages 部署更新。
5. 若浏览器仍显示旧版，按 Ctrl + Shift + R 或使用无痕窗口测试。

本次改动：
- 询问王雨桐／物业群时，需玩家选择要发送的话，回复延时逐步送达。
- 米米首轮回复、晚安往来均拆为独立消息阶段；完整回复后才能入睡。
- 聊天列表摘要取自实际已经显示的最后一条消息；取消桌面显示房号。
- 对旧版本浏览器存档提供迁移，已被自动跳过的部分对话可重新参与。

注意：ZIP 是项目文件集合，不要只上传 index.html，也不要把 ZIP 直接当作网页上传。
存档仅保存在当前浏览器。
